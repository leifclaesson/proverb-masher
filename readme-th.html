สุภาษิตมั่ว — ฉบับภาษาไทย 🇹🇭

เรื่องเล่า: คนเขียนเป็นคนกวนๆ มาตั้งแต่เด็กแล้ว
โปรแกรมนี้เป็นของเก่าที่ Leif เขียนเองตอนยังหนุ่มๆ ราวปี ค.ศ. ๑๙๙๖ (พ.ศ. ๒๕๓๙) เอามาทำเป็นเวอร์ชันไทยให้ดูเล่นๆ

ที่มา

ตอนนั้น Leif อยู่ในวงการที่เรียกว่า "เดโมซีน" (demoscene) คือกลุ่มโปรแกรมเมอร์ที่แข่งกันเขียนโปรแกรมโชว์กราฟิกและเสียงเจ๋งๆ บนเครื่องคอมพิวเตอร์เก่าที่แรงน้อยมาก เขาใช้ฉายาในวงการว่า "Liket of Goto10" ชื่อ "Liket" นี้ เพื่อนๆ เป็นคนตั้งให้แล้วมันก็ติดปากมาตั้งแต่นั้น ไม่ใช่ชื่อที่เจ้าตัวตั้งเอง — มันล้อมาจากพิธีกรทีวีสวีเดนชื่อดัง Leif "Loket" Olsson (คนเขียนก็ชื่อ Leif เหมือนกัน) คำว่า "Loket" ที่แปลว่า "หัวรถจักร" เลยโดนบิดเป็น "Liket" ที่แปลว่า "ศพ" ส่วน "Goto10" มาจากการที่เขายืนกราน จะเขียนภาษา BASIC (คำสั่ง GOTO 10)

แล้ววันหนึ่งเขาก็เขียนโปรแกรมจิ๋วๆ ชื่อ COOKIE ด้วยภาษา PowerBASIC บนเครื่อง DOS หน้าที่ของมันมีอย่างเดียวคือ เอาสุภาษิตสวีเดนมา "สับ" รวมกันให้กลายเป็นเรื่องไร้สาระ (ต้นฉบับสวีเดนก็เล่นได้บนเว็บนี้แหละ กดปุ่ม SV ข้างบน)

มันทำงานยังไง

แต่ละสุภาษิตถูกผ่าครึ่งด้วยเครื่องหมาย | เป็น ท่อนหน้า กับ ท่อนหลัง แล้วโปรแกรมก็เอาท่อนหน้าของบทหนึ่ง ไปแปะกับท่อนหลังของอีกบท

รักวัว | ให้ผูก รักลูก | ให้ตี → รักวัว ให้ตี 🐮

เคล็ดลับที่ทำให้มัน "ฮาแบบมีหลักการ" มีสองอย่าง:

๑. สุ่มกลุ่มแบบถ่วงน้ำหนัก — กลุ่มไหนมีสุภาษิตเยอะ ก็ยิ่งถูกหยิบมาเล่นบ่อย Leif เลยจัดให้กลุ่ม ๑ (สถานการณ์ | คำสอน) ใหญ่ที่สุด เพราะกลุ่มนั้นมั่วแล้วฮาสุด

๒. กฎ "เหี้ยเอ้ย" — ต้นฉบับสวีเดนตั้งชื่อ label ของลูปวนซ้ำนี้ว่า fanheller ซึ่งเป็น คำด่า (ภาษาสวีเดน ~ "ไม่มีทางโว้ย / เหี้ยอะไร") เวอร์ชันไทยเลยขอแปลคำด่าให้เป็นไทยซะเลย พอโปรแกรมสุ่มได้บทเดิมซ้ำเมื่อไหร่ มันก็เด้งกลับไปสุ่มใหม่ ("เหี้ยเอ้ย เอาใหม่!") ท่อนหน้ากับท่อนหลังจึงมาจากคนละบทเสมอ แปลว่ามัน ไม่มีทางเผลอพ่นสุภาษิตจริงๆ ออกมาได้เลย ผิดได้อย่างเดียว

เวอร์ชันไทยนี้ใช้สุภาษิตไทย ของจริง จัดกลุ่มให้ไวยากรณ์เข้ากันได้ ผลที่ออกมาเลย "อ่านลื่น แต่ความหมายเพี้ยน" พอดี (ภาษาไทยเว้นวรรคระหว่างวลีอยู่แล้ว รอยต่อตรงที่สับเลยกลายเป็นการเว้นวรรค ที่ดูเป็นธรรมชาติพอดิบพอดี)

แต่ละสุภาษิตยังมี คำแปลอังกฤษ ของท่อนหน้า/ท่อนหลัง เก็บไว้ด้วย ออกแบบให้สลับกันแล้วยังถูกไวยากรณ์อังกฤษ เวลาโปรแกรมสับบทไทย มันเลยโชว์คำแปลอังกฤษของบทมั่วออกมาให้ด้วย (ไว้เทียบเรียนภาษาไปในตัว) ภาษาอังกฤษ "มั่วตรงกับไทย" เป๊ะ เพราะใช้ดัชนีคู่เดียวกัน

ทำไมเวอร์ชันเดสก์ท็อปต้องมี GUI ด้วย? ก็เพราะภาษาไทยมันเรนเดอร์เพี้ยนๆ ในคอนโซล... Leif เลยลงทุนทำหน้าต่าง GUI พร้อมปุ่มขึ้นมาทั้งอัน แค่เพื่อให้สุภาษิต มั่วๆ อ่านสวยขึ้น 😅 (บนเว็บนี้ก็เหมือนกัน — ภาษาไทยได้ฟอนต์จริง ไม่ใช่ฟอนต์คอมโบราณปลอมๆ แถมปุ่มยังถูกตรึงไว้ "บนสุด" จะได้ไม่ขยับหนีเมาส์เวลาข้อความยาวไม่เท่ากัน — นิสัยเนี้ยบระดับ OCD ของคนเขียน ยังอยู่ครบทุกดีเทล)

ตัวอย่างของจริงที่มันพ่นออกมา

ใครอยากเพิ่มสุภาษิตเองก็ได้ — ไฟล์ข้อมูลอยู่ใน ซอร์สโค้ด เติมบรรทัด ท่อนหน้า|ท่อนหลัง|EN head|EN tail เข้าไปในกลุ่มที่ไวยากรณ์เข้ากัน (ระวังให้ครึ่งซ้าย/ขวาสลับกับเพื่อนในกลุ่ม แล้วยังอ่านรู้เรื่องทั้งไทยและอังกฤษ) ลองหาคู่ที่มั่วแล้วฮาที่สุดดู
