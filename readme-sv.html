COOKIE — the Ordspråk scrambler (revived)

Provenance. COOKIE.BAS by Leif Claesson (Liket of Goto10), ~1996, written in PowerBASIC for DOS. Recovered decades later from an archaeology dig through old disks, alongside its data file ORDSPRÅK.TXT (CP437) and a pile of tweak-mode VGA .256 resolution tables from the same era. The original data file is served on this site byte-for-byte pristine — still CP437, decoded by a hand-spelled 128-entry table, because that's what DOS text actually was.

It is a Swedish proverb scrambler. Each proverb is split by a pipe into a HEAD and a TAIL. The program prints one proverb's HEAD glued to a different proverb's TAIL, producing mangled folk wisdom:

En lögnare leka bäst. · Allt guld i kungariket förlänger livet. · Ett gott samvete skramlar mest.

The data format

ORDSPRÅK.TXT is dead simple, and the file is half the joke — the comedy is seeded into the data, not just the code.

TokenMeaning
# ; ' at line startcomment, ignored
head|taila proverb, split at the pipe into interchangeable halves
* on its own lineend this section, start the next
** on its own lineend of file — everything after is ignored

Proverbs are bucketed into sections of grammatically-interchangeable halves, so any HEAD in a section fits any TAIL in the same section and still parses as Swedish. Section 1 is deliberately overstuffed with fake dyr/dyrt/dyra ("expensive") decoys planted next to the real Bränt/Tomma/Lika/Gamla ones — those decoys are the payload, and (see below) the engine is rigged to fire them often. The three proverbs parked past the ** terminator are intentional spares the program can never reach.

Bränt barn | skyr elden Tomma tunnor | skramlar mest → Bränt barn skramlar mest.

The engine, and why it's clever

1. Population-weighted section choice. It does not pick a section uniformly. It builds a flat table grupp[] with one slot per proverb, each holding that proverb's section number, then picks a random slot. So a fat section is chosen in proportion to how many proverbs it holds — which is why the decoy-stuffed Section 1 dominates the output. The weighting is what makes the joke land reliably.

2. fanheller: ("fan heller" — hell no) is the retry label that rejects two identical rolls. Because HEAD and TAIL must come from different lines, the program is structurally incapable of printing an intact line back at you. It can only ever be wrong, which is the entire point. Every later edition has translated the curse along with the proverbs: English swears in English, Thai in Thai (เหี้ยเอ้ย), Russian in Russian («чёрта с два»).

Note the deliberate pre-mashed proverb planted straight in the 1996 data — stutter and all: Den som gapar efter galen fågel ser inte ser inte skogen för alla ben.

This site

The web edition (2026) is the engine's fifth port — PowerBASIC → Python → Rust → JavaScript — and reads the very same data format the DOS original did. The English mirror shown under the Swedish output lives in a sidecar file, so the 1996 data file never had to be touched.
