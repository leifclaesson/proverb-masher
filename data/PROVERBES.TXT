#               Proverbes 0.5  —  version française d'Ordsprak 0.1-et-quelques
#               original : Leif Claesson (Liket of Goto10), ~1996
#
#       Pour Dan et pour Seb. Deux amis qui ne se connaissent pas, une
#       seule langue -- et c'est celle que je ne parle pas. Dan, on se
#       parle anglais depuis 2017 : ton anglais te demande un effort, mon
#       français en demanderait bien davantage. Voici donc un programme
#       qui écrit le français plus mal que nous deux réunis. Seb, ça fait
#       cinq ans que tu écrivais dans le vide sans que je le voie ;
#       celui-ci arrive avec cinq ans de retard, mais il arrive.
#
#       LE MOT « CHER » EST TOUTE LA BLAGUE. Devant le nom il veut dire
#       aimé, derrière le nom il veut dire coûteux, et le programme le met
#       toujours derrière. Un cher ami, un ami cher : même mot, deux sens,
#       et c'est la place qui décide. Dans les autres versions -- suédois,
#       néerlandais, grec, polonais -- l'adjectif-appât se met devant le
#       nom. En français il a fallu le faire passer de l'autre côté, sinon
#       les faux proverbes devenaient des déclarations d'amitié.
#
#       ET LES QUATRE FORMES SE PRONONCENT PAREIL. cher, chère, chers,
#       chères : quatre orthographes, un seul son. La version grecque avait
#       six formes et on les entendait toutes les six. Ici l'accord existe
#       sur le papier et nulle part ailleurs -- lisez le fichier à voix
#       haute et la grammaire disparaît.
#
#       Le format est très simple. Les proverbes sont rangés en groupes à
#       l'intérieur desquels les moitiés sont grammaticalement
#       interchangeables, et la couture est une barre verticale (|). Une
#       étoile seule (*) ouvre le groupe suivant. Deux étoiles (**), c'est
#       la fin du fichier : le programme ne lit rien au-delà.
#
#       Chaque ligne a quatre champs :  tête|queue|EN head|EN tail
#       La traduction anglaise est mélangée avec le MÊME couple d'indices,
#       donc les bêtises anglaises suivent exactement les françaises. Ici
#       ce n'est pas une politesse faite au lecteur : c'est comme ça que
#       l'auteur relit son propre cadeau.
#
#       LES VERBES FRANÇAIS S'ACCORDENT EN NOMBRE, comme en anglais, en
#       néerlandais, en grec et en polonais, et contrairement au suédois,
#       au thaï et au russe. Un + en début de ligne veut dire SUJET AU
#       PLURIEL, et la queue porte elle-même les deux formes :
#           (e/ent)        premier groupe -- et on n'entend rien du tout
#           (t/ssent)      deuxième groupe -- là, on entend
#           (est/sont)     le verbe être, qui ne ressemble à rien
#       C'est exactement l'inverse du grec : là-bas le seul verbe non
#       marqué était la copule et tout le reste s'entendait. Ici la copule
#       est le verbe le plus bruyant du fichier, et les neuf dixièmes des
#       verbes français sont marqués à l'écrit et muets à l'oreille.
#
#       LA NÉGATION VOYAGE DANS LA PARENTHÈSE. « ne » s'élide devant une
#       voyelle mais pas devant une consonne, donc (n'est/ne sont) et
#       jamais ne (est/sont). C'est la seule règle qu'il a fallu ajouter
#       pour le français, et c'est une règle de fichier, pas de programme.
#
#       LE POSSESSIF EST GRATUIT. En français il s'accorde avec la chose
#       possédée, pas avec le possesseur : « chacun voit midi à sa porte »
#       garde « sa » quel que soit le sujet, parce que c'est « porte » qui
#       décide. Seul le nombre change, (sa/leur). En anglais il fallait
#       (its/their) ; ici le genre n'entre jamais dans la queue.
#
#       LE GROUPE, C'EST L'ACCORD EN GENRE. Les adjectifs attributs
#       s'accordent (bon, bonne, bons, bonnes), donc les queues du groupe 1
#       sont UNIQUEMENT des groupes verbaux : pas d'attribut, pas de
#       participe passé avec être, qui s'accorderait lui aussi. Aucun code
#       nouveau n'a été nécessaire pour ça. Le « groupe » de 1996 était
#       déjà une classe d'équivalence de genre et de nombre -- le suédois
#       ne l'avait simplement jamais poussé aussi loin.
#
#       ET LE PLURIEL CACHE LE GENRE. « les » sert aux deux genres, donc
#       au pluriel c'est l'appât tout seul qui porte l'accord : rien
#       d'autre dans la phrase ne viendrait contredire « les murs chères ».
#
#       LA PONCTUATION VOYAGE DANS LA TÊTE (en russe, c'est l'inverse) :
#       le français veut une virgule après une subordonnée placée en tête,
#       et cette subordonnée est justement la tête. Voir le groupe 5.
#
#       Le groupe 1 est volontairement bourré de faux proverbes « chers ».
#       Dans l'original suédois c'étaient de faux dyr/dyrt/dyra, trois
#       formes ; le grec en demandait six ; le français en demande quatre.
#       L'appât EST la blague, et le tirage pondéré par groupe fait qu'il
#       tombe plus souvent que tout le reste.
#
#       Enfin, le proverbe déjà mâché que l'auteur avait planté dans le
#       fichier en 1996, bégaiement compris, est resté. En grec il jouait
#       sur φύλλα, qui veut dire feuilles ET pâte filo. Le français a la
#       même feuille : on ne voit plus la forêt à cause du mille-feuille.
#
