#               Sprichwörter 0.5  —  deutsche Fassung von Ordsprak 0.1-und-etwas
#               Original: Leif Claesson (Liket of Goto10), ~1996
#
#       Für Peter und für Torsten. Der eine grüßt mit "Servus", der
#       andere kommt aus Regensburg, wo man das genauso sagt — und diese
#       Fassung ist trotzdem in Hochdeutsch, also in der Sprache, die
#       keiner von euch beiden zu Hause spricht. Geschrieben hat sie am
#       Ende sowieso ein Schwede.
#
#       Peter, die Sprachwürfelei war deine Idee — dass das Ding von
#       allein weiterzieht statt bei einer Sprache stehenzubleiben. Hier
#       ist die neunte, auf die es jetzt fallen kann. Sie ist von allen
#       neun die störrischste, und das ist die Pointe.
#
#       Torsten, deine Mails fangen mit der Warnung an, dass es lang
#       wird, und dann liegt das ganze Durcheinander sauber sortiert da,
#       mit genau einer Frage am Ende. Dieses Programm nimmt dasselbe
#       Deutsch auseinander und legt es in der falschen Reihenfolge
#       wieder hin.
#
#       TEUER IST DER GANZE WITZ, und Deutsch ist die einzige Fassung, in
#       der der Köder gar nicht erst übersetzt werden musste. Schwedisch
#       "dyr", niederländisch "duur", deutsch "teuer" — ein einziges
#       germanisches Wort in drei Schreibweisen. Aber "dyr" und "duur"
#       heißen nur teuer im Sinne des Preises; "teuer" heißt daneben auch
#       lieb ("mein teurer Freund", "die teure Heimat"), genau wie
#       russisch "дорогой", polnisch "drogi" und französisch "cher". Das
#       Deutsche steht also in beiden Lagern gleichzeitig: dasselbe Wort
#       wie 1996 UND beide Bedeutungen. Und das englische "dear" ist
#       dasselbe Wort noch einmal, mit denselben zwei Bedeutungen — daher
#       steht im englischen Spiegel dieser Fassung "dear" und nicht
#       "expensive". Die anderen Fassungen mussten sich entscheiden.
#
#       Das Dateiformat ist sehr einfach. Die Sprichwörter stehen in
#       Gruppen, innerhalb derer die Hälften grammatisch austauschbar
#       sind; die Naht ist ein senkrechter Strich (|). Ein einzelner *
#       eröffnet die nächste Gruppe. ** ist das Dateiende: was danach
#       kommt, liest das Programm nicht mehr.
#
#       Jede Zeile hat vier Felder:  Kopf|Schwanz|EN head|EN tail
#       Die englische Übersetzung wird mit DEMSELBEN Indexpaar gemischt
#       wie das Deutsche, der englische Unsinn läuft also exakt parallel.
#
#       DEUTSCHE VERBEN RICHTEN SICH NACH DER ZAHL, wie die englischen,
#       niederländischen, griechischen, polnischen und französischen und
#       anders als die schwedischen, thailändischen und russischen. Also
#       macht diese Fassung dasselbe wie die englische: ein + am
#       Zeilenanfang heißt SUBJEKT IM PLURAL, und der Schwanz trägt beide
#       Formen selbst mit sich:
#           mach(t/en)        Endung — die Naht sitzt hinten
#           f(ällt/allen)     Umlaut — die Naht rutscht in den Stamm
#           br(icht/echen)    e wird i — dasselbe Verb wie im
#                             niederländischen br(eekt/eken), anderer
#                             Mechanismus: dort ein offener Vokal, hier
#                             eine Hebung
#           (ist/sind)        gar keine Naht, kein gemeinsamer Buchstabe
#           (isst/essen)      dasselbe noch einmal, und diesmal ist es
#                             nicht einmal ein unregelmäßiges Verb
#       Vier Nahtsorten in einer Datei — das hat keine der acht Fassungen
#       vorher zusammen gehabt. Deshalb trägt die Markierung beide Formen,
#       statt eine aus der anderen abzuleiten: keine Endungsregel der Welt
#       kommt an die Naht von f(ällt/allen) heran.
#
#       DIE NAHT DARF IM DEUTSCHEN NUR AN ZWEI STELLEN LIEGEN, und das ist
#       der eigentliche Unterschied zu allen bisherigen Fassungen:
#           1. an einer Satzgrenze, oder
#           2. unmittelbar hinter dem Vorfeld, also hinter dem EINEN Glied,
#              das vor dem finiten Verb steht.
#       Alles andere zerschneidet die Satzklammer. "Man soll den Tag nicht
#       vor dem Abend loben" hat sein finites Verb vorn und seinen
#       Infinitiv ganz hinten; wer irgendwo in der Mitte schneidet, lässt
#       ein Verb ohne seinen Partner zurück. Deshalb steht in Gruppe 4
#       nicht "Man soll den Tag|nicht vor dem Abend loben", sondern das
#       Objekt im Vorfeld: "Den Tag|soll man nicht vor dem Abend loben".
#       Dasselbe von der anderen Seite: im Nebensatz steht das Verb ganz
#       hinten, also ist ein Nebensatz immer ganz Kopf und nie halb
#       (Gruppen 2 und 6).
#
#       DER KASUS LÄUFT ÜBER DIE NAHT, und dafür gibt es keine Markierung.
#       Das + kennt nur die Zahl. Welchen Fall der Kopf trägt, bestimmt
#       aber das Verb im Schwanz: "Einem geschenkten Gaul schaut man nicht
#       ins Maul" verlangt Dativ, "Schlafende Hunde soll man nicht wecken"
#       Akkusativ, und geklebt wird beides gleich wahrscheinlich. Eine
#       Markierung könnte das nicht retten — der Kopf müsste in vier
#       Fällen mitgeliefert werden, mit Artikel und Adjektiv, und das ist
#       keine Klammerform mehr, sondern eine Deklinationstabelle.
#       Die Lösung ist deshalb keine neue Maschinerie, sondern die
#       Gruppierung: JEDE GRUPPE IST EINE KASUSKLASSE. Gruppe 4 ist
#       durchgehend Akkusativ, Gruppe 5 durchgehend Dativ, und deswegen
#       gibt es Gruppe 5 überhaupt. Das ist derselbe Griff, mit dem die
#       polnische Fassung das Genus des Präteritums erledigt hat, nur eine
#       Etage tiefer: die Gruppe von 1996 WAR schon eine Äquivalenzklasse,
#       das Schwedische hat sie bloß nie so hart angefasst.
#
#       WAS DIE MASCHINERIE NICHT KANN, offen gesagt: das Possessivum.
#       Sein Stamm richtet sich nach dem Genus des BESITZERS, und der
#       steht im Kopf — "Jedes Ding hat seine Zeit", aber "Die Hoffnung hat
#       IHRE Zeit". (seine/ihre) trägt nur die Zahl, das Genus fehlt, und
#       eine geklebte Zeile wäre in der Hälfte der Fälle schlicht falsch.
#       Englisch (its/their), niederländisch (zijn/hun) und die
#       französische Fassung kommen alle davon, weil ihr Possessivum kein
#       Genus des Besitzers kennt. Diese Fassung kommt nicht davon, also
#       steht in KEINEM deutschen Schwanz ein Possessivum, und im
#       englischen Spiegel dann auch keins. "Jedes Ding hat seine Zeit"
#       und "Jeder Topf findet seinen Deckel" sind genau daran
#       gescheitert. Eine Markierung mit drei Genera plus Plural wäre
#       machbar, aber sie wäre eine Motoränderung für zwei Sprichwörter,
#       und dafür ist sie zu teuer.
#       Aus demselben Grund fehlt "Den Ast soll man nicht absägen, auf dem
#       man sitzt": das Relativpronomen im Schwanz richtet sich nach dem
#       Genus des Kopfes. Und "Aller guten Dinge sind drei" fehlt in
#       Gruppe 1, weil sein Kopf im Genitiv steht.
#
#       DIE ENDUNG HÄNGT AM ARTIKEL, nicht nur am Substantiv. Gruppe 1 ist
#       absichtlich mit falschen "teuren" Sprichwörtern vollgestopft. Im
#       schwedischen Original waren es drei Formen dyr/dyrt/dyra, im
#       Polnischen vier Gestalten auf fünf Plätzen. Das Deutsche hat im
#       Nominativ allein auch vier Gestalten — teure, teurer, teures,
#       teuren — aber sie verteilen sich nach einer Achse, die keine
#       frühere Fassung zeigen konnte, weil ihr die Artikel fehlten:
#           der teure Apfel     ein teurer Apfel      (dasselbe Wort,
#           die teure Zeit      eine teure Schwalbe    derselbe Fall,
#           das teure Blut      ein teures Kind        andere Endung —
#           die teuren Wände    teure Kleider          der Artikel
#                                                      entscheidet)
#       Und "teuer" verliert sein e, sobald eine Endung kommt: teuer ->
#       teur-. Die Köder SIND der Witz, und die nach Gruppengröße
#       gewichtete Auswahl sorgt dafür, dass sie am häufigsten fallen.
#
#       DIE INTERPUNKTION FÄHRT IM KOPF MIT (im Russischen umgekehrt, dort
#       im Schwanz): das Deutsche will sein Komma hinter dem vorangestellten
#       Nebensatz, und der Nebensatz steht nun einmal im Kopf. Siehe
#       Gruppen 2 und 6. Ein Kopf ohne Nebensatz hat schlicht kein Komma.
#
