#       a Orban wciąż siada ludziom na kolanach.

#       (I tak, wiadomo, kto znalazł tego buga, którego nie dało się
#       powtórzyć. Port serwera wewnętrznego. Sześć tygodni. Dzięki.)
#
#       Pułapka dla Szweda -- a Szwed to napisał: polskie TAK brzmi
#       dokładnie jak szwedzkie TACK, czyli "dziękuję". Polak, który
#       gorąco się z tobą zgadza, dla szwedzkiego ucha dziękuje bez końca.
#       A samo szwedzkie "tak" to sufit, więc równie dobrze może krzyczeć
#       "sufit, sufit, sufit". I jeszcze "Sto lat!", które po szwedzku
#       słychać jako "sto leniwych" (lat = leniwy).
#
#       DROGI ZNACZY DWIE RZECZY, i o to tu chodzi. W szwedzkim oryginale
#       wabikiem było "dyr" -- drogi wyłącznie w sensie ceny. Po polsku to
#       samo słowo otwiera list. Każde podrobione przysłowie w grupie 1
#       mówi więc do ciebie "drogi", a wabik w liczbie mnogiej
#       męskoosobowej trafia prosto w "Drodzy przyjaciele". No i "droga"
#       to jeszcze droga: greckie "paroimia" znaczy "przy drodze", a tu ta
#       droga siedzi w samym wabiku.
#
#       Format pliku jest bardzo prosty. Przysłowia siedzą w grupach, w
#       których połówki są gramatycznie wymienne, a szew to pionowa
#       kreska (|). Samotna * otwiera następną grupę. ** to koniec pliku:
#       tego, co dalej, program już nie czyta.
#
#       Każdy wiersz ma cztery pola:  głowa|ogon|EN head|EN tail
#       Angielskie tłumaczenie miesza się TĄ SAMĄ parą losowań, więc
#       angielskie bzdury lecą dokładnie równolegle do polskich.
#
#       POLSKIE CZASOWNIKI ODMIENIAJĄ SIĘ PRZEZ LICZBĘ, tak jak angielskie,
#       niderlandzkie i greckie, a inaczej niż szwedzkie, tajskie i
#       rosyjskie. Dlatego ta wersja robi to samo co angielska: + na
#       początku wiersza znaczy PODMIOT W LICZBIE MNOGIEJ, a ogon niesie
#       oba tryby sam ze sobą:
#           (a/ają)      pada / padają
#           (i/ą)        myli / mylą
#           (zie/zą)     gryzie / gryzą
#       I szew nie zawsze pada na końcówkę: ro(śnie/sną) przesuwa go w
#       głąb tematu i zabiera ze sobą spółgłoskę (ś/s), id(zie/ą) tnie w
#       środku zbitki, a (jest/są) nie ma ze sobą wspólnej ANI JEDNEJ
#       litery. Dlatego sygnatura niesie OBA tryby, zamiast wyprowadzać
#       jeden z drugiego.
#
#       DWIE KOPULE, JEDNA OBOK DRUGIEJ. "Jest/są" odmienia się dokładnie
#       odwrotnie niż greckie "είναι", które w obu liczbach brzmi tak
#       samo. A polskie "to" (Ciekawość to pierwszy stopień do piekła) nie
#       odmienia się wcale -- za to angielskie lustro i tak musi tam
#       postawić (is/are).
#
#       GRUPA TO ZGODA RODZAJU. Polski czas przeszły ma rodzaj (był, była,
#       było, byli, były), więc w grupie 1 ogonem może być WYŁĄCZNIE
#       fraza w czasie teraźniejszym: żadnego orzecznika przymiotnikowego
#       i żadnego czasu przeszłego. Grecka wersja doszła do tej samej
#       zasady od strony przymiotnika; polska dochodzi od strony
#       czasownika. ("Nadzieja umiera ostatnia" wypadło właśnie przez to.)
#       Nowego kodu to nie wymagało. Grupa z 1996 BYŁA już klasą
#       równoważności rodzaju i liczby -- szwedzki po prostu nigdy jej
#       tak nie przycisnął.
#
#       Grupa 1 jest celowo przeładowana podrobionymi "drogimi"
#       przysłowiami. W szwedzkim oryginale były trzy formy dyr/dyrt/dyra.
#       Polski ma PIĘĆ MIEJSC, ale tylko CZTERY KSZTAŁTY, bo rodzaj nijaki
#       w liczbie pojedynczej i niemęskoosobowy w mnogiej to to samo
#       słowo:
#           drogi pies      droga ryba      drogie jabłko
#           drodzy ludzie   drogie ściany
#       Rodzajnika nie ma żadnego, więc cała zgoda siedzi w samym
#       przymiotniku -- a "drodzy" to już nie wymiana końcówki, tylko
#       przestawienie tematu (g -> dz). Wabik JEST żartem, a ważona
#       wielkością grupy losowanie dba, żeby wypadał najczęściej.
#
#       INTERPUNKCJA JEDZIE W GŁOWIE (w rosyjskiej wersji odwrotnie, w
#       ogonie): polski chce przecinka przed "ten/tam/to", a to wypada
#       dokładnie na szwie. Patrz grupa 5.
#
