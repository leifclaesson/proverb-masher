#  สำหรับคนที่ทำงานกับเลย์ฟ. เจ้าของโปรแกรมนี้เขียนมันตอนเป็นวัยรุ่น
#  เมื่อสามสิบปีก่อน แล้วสามสิบปีต่อมาก็ยังมานั่งแก้มันอยู่ -- ซึ่งบอก
#  อะไรเกี่ยวกับเขาได้เยอะกว่าตัวโปรแกรมเสียอีก.
#
#  ชื่อไทยของเขาคือ เลย์ฟ กลอซน. ท้ายนามสกุลเป็น "ซน" เพราะเขาเลือกเอง
#  โปรแกรมที่จงใจทำสุภาษิตให้พัง เขียนโดยคนที่ชื่อในภาษาไทยแปลว่าซน
#  ก็ถือว่าตรงกันดี.
#
#  กับดักสำหรับคนสวีเดน -- และคนสวีเดนเป็นคนเขียนไฟล์นี้: คำว่า "ฝัน"
#  ในภาษาไทย ออกเสียงเกือบเหมือนคำว่า fan ในภาษาสวีเดน ซึ่งแปลว่าผี
#  ซาตาน และเป็นคำหยาบที่ต้นฉบับปี ๑๙๙๖ ใช้ตั้งชื่อลูปวนซ้ำในโปรแกรม
#  (fanheller). ลูปที่ด่าในภาษาสวีเดน กลับฝันในภาษาไทย.
#
#  และคำว่า "ขัน" ในไฟล์นี้มีสามความหมายพร้อมกัน: ภาชนะตักน้ำ, เสียงไก่,
#  และตลก. ไฟล์ที่มีหน้าที่ทำให้คนขำ เขียนในภาษาที่เสียงไก่กับเสียงหัวเราะ
#  เป็นคำเดียวกัน.
#
#  รูปแบบไฟล์:  ท่อนหน้า|ท่อนหลัง|EN head|EN tail
#  จับสุภาษิตที่เข้ากันได้ทางไวยากรณ์ไว้กลุ่มเดียวกัน แล้วใส่ | ตรงรอยต่อ
#  ช่องที่ ๓ และ ๔ คือคำแปลอังกฤษของท่อนหน้า/ท่อนหลัง -- ออกแบบให้สลับกัน
#  แล้วยังถูกไวยากรณ์อังกฤษด้วย เวลาสับ ภาษาอังกฤษเลยมั่วตามไทยเป๊ะ
#  * ขึ้นต้นบรรทัด = ขึ้นกลุ่มใหม่   ** = จบไฟล์ (บรรทัดถัดไปถูกข้าม)
#
#  ภาษาไทยไม่ผันคำกริยา ไม่มีเพศ ไม่มีพจน์ ไม่มีคำนำหน้านาม เพราะฉะนั้น
#  ไฟล์นี้ไม่มีเครื่องหมาย (s) หรือ (x/y) แบบฉบับอังกฤษ ดัตช์ กรีก โปแลนด์
#  และฝรั่งเศสเลยสักตัวเดียว -- เหมือนฉบับสวีเดนกับรัสเซีย.
#
#  คำล่อในไฟล์นี้คือ "แพง". ต้นฉบับปี ๑๙๙๖ แอบใส่สุภาษิตปลอมที่มีคำว่า
#  dyr/dyrt/dyra (แพง) ปนไว้ในกลุ่มที่ ๑ และคำล่านี่แหละคือมุกหลักของ
#  โปรแกรม. ทุกฉบับต้องผันคำนี้ตามไวยากรณ์ของตัวเอง: สวีเดน ๓ รูป,
#  ดัตช์ ๒, กรีก ๖, ฝรั่งเศส ๔. ภาษาไทยใช้รูปเดียว เพราะไม่มีอะไรให้ผัน.
#
#  และคำล่าไทยวางไว้ "หลัง" คำนาม เหมือนฝรั่งเศส -- แต่ฝรั่งเศสต้องย้าย
#  มันไปไว้ข้างหลังเอง ส่วนภาษาไทยไม่มีข้างหน้าให้เลือกตั้งแต่แรก.
#
#  ที่แปลกกว่านั้น: คำวิเศษณ์ไทยเป็นคำกริยาในตัวเอง แปลว่า "หมาแพง"
#  อ่านได้สองแบบพร้อมกัน -- "หมาที่แพง" (ยังไม่จบประโยค) กับ "หมานั้นแพง"
#  (จบประโยคแล้ว). ฉบับอื่นคำล่าเป็นแค่คำนามที่รอภาคแสดง ของไทยเป็น
#  ประโยคเต็มไปแล้วก่อนที่ท่อนหลังจะมาต่อ.
#
#  บังเอิญคำว่า "กำแพง" มีคำว่า "แพง" ซ่อนอยู่ในตัวมันเอง.
#
#  ช่องว่างในภาษาไทยไม่ได้คั่นคำ แต่คั่นวลี ตรงรอยต่อโปรแกรมจึงเติม
#  ช่องว่างให้ถูกที่พอดี -- แต่แปลว่าท่อนหน้าทุกท่อนต้องยืนเป็นวลีได้เอง
#  และห้ามขึ้นต้นท่อนหลังด้วย ๆ เพราะไม้ยมกซ้ำคำที่อยู่ "ข้างหน้า" มัน
#  ซึ่งจะกลายเป็นซ้ำคำสุดท้ายของท่อนหน้าข้ามรอยต่อไปทุกคู่.
#
