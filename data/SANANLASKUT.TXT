#       LÄHDE: jokainen tämän tiedoston sananlasku on poimittu Wiktionaryn
#       luokasta Category:Finnish_proverbs (luettu 2026-08-10), ei muistista.
#       Versio 0.1 kirjoitettiin mallin omasta muistista ja se HYLÄTTIIN --
#       Leifin pyynnöstä ja aivan oikein, koska kukaan täällä ei osaa suomea
#       eikä olisi huomannut keksittyä sananlaskua. Ainoa rivi, joka EI ole
#       aito, on ryhmän 2 "metsää jaloilta", ja se on tahallinen: se on
#       vuoden 1996 sormenjälki, joka kulkee jokaisessa laitoksessa.
#       Sanajärjestystä on paikoin käännetty (esim. "sitä tikulla silmään
#       joka vanhoja muistelee" -> "Joka vanhoja muistelee, sitä tikulla
#       silmään") ja pitkistä sananlaskuista on toisinaan otettu vain
#       ensimmäinen puolisko. Sanat ovat lähteen sanoja.
#
#       Tiedostomuoto on hyvin yksinkertainen. Sananlaskut ovat ryhmissä,
#       joiden sisällä puolikkaat ovat kieliopillisesti vaihdettavissa; sauma
#       on pystyviiva (|). Yksinäinen * aloittaa seuraavan ryhmän. ** on
#       tiedoston loppu: sen jälkeistä ohjelma ei lue.
#
#       Jokaisella rivillä on neljä kenttää:  pää|häntä|EN head|EN tail
#       Englanninkielinen peili sekoitetaan SAMALLA indeksiparilla kuin suomi,
#       joten englanniksi tulee täsmälleen sama hölynpöly -- ei käännöstä
#       lopputuloksesta vaan sama sekoitus.
#
#       SUOMI TAIVUTTAA LUVUN MUKAAN, kuten englanti ja toisin kuin ruotsi,
#       thai ja venäjä. Siksi tämä laitos tekee saman tempun kuin
#       englanninkielinen: rivin alussa oleva + tarkoittaa, että SUBJEKTI ON
#       MONIKOSSA, ja häntä kantaa itse molemmat muodot:
#           kulta(a/avat)   yksikkö kultaa, monikko kultaavat
#           (on/ovat)       yksikkö on, monikko ovat
#           (ei/eivät)      KIELTOVERBI taipuu -- pääverbi jää kieltomuotoon
#                           eikä muutu lainkaan
#           soke(a/ita)     PREDIKATIIVI taipuu myös. Tätä ei ole tarvittu
#                           yhdessäkään aiemmassa laitoksessa: hollanti ja
#                           saksa jättävät nominaaliosan tahallaan törmäämään
#                           ("Holle vaten zijn koning"), mutta suomessa
#                           predikatiivin kongruenssi on pakollinen, joten
#                           merkintä ulottuu verbistä adjektiiviin asti.
#
#       Vokaalisointu ratkaisee -vat/-vät -päätteen, ja sen ratkaisee sanan
#       OMA vokaalisto: kolise(e/vat) mutta teke(e/vät) -- sama sauma, eri
#       pääte. Sointu ei koskaan ylitä saumaa, koska pääte kiinnittyy omaan
#       sanaansa. Juuri siksi merkintä kantaa molemmat muodot eikä johda
#       toista toisesta: mikään päätesääntö ei tiedä vokaalisoinnusta.
#
#       Ryhmä 1 sisältää valheellisia "kalliita" sananlaskuja -- mutta vain
#       VIISI, ja tässä tämä laitos poikkeaa kaikista kymmenestä muusta.
#       Muissa niitä on 22-38 % ryhmän 1 riveistä; täällä alle 9 %.
#       //Leif, 2026-08-10: "We should only add it where it makes it funnier.
#       And only a handful." -- ja sitten hän valitsi ne itse: pääsky,
#       tieto, kivi, kynä, kertaus. ÄLÄ LISÄÄ NIITÄ. Määrä ei ole vitsi;
#       osuma on, ja osuman valitsee tekijä.
#       Yksi viidestä osuu alkuperäisen omaan istutukseen ilman että sitä
#       haettiin: vuoden 1996 tiedostossa on "En dyr svala | gör ingen
#       sommar", ja hän valitsi pääskyn.
#       Peili sanoo EXPENSIVE eikä dear: yhdeksän laitosta yhdestätoista
#       tekee niin, ja saksa on dokumentoitu poikkeus eikä sääntö.
#
#       Ruotsalaisessa alkuperäisessä täällä oli valheellisia
#       "dyr/dyrt/dyra" -- ja kallis on suomeksi sekä hintava että rakas,
#       aivan kuten дорогой, drogi, cher, caro ja teuer. Suomi ei kuitenkaan
#       ole indoeurooppalainen kieli, joten tämä ei ole sama SANA vaan sama
#       KUVA. Kaksi aitoa riviä tulee samaan
#       leikkiin ilmaiseksi: "Terveys on kultaa kalliimpi" (ryhmä 1) ja
#       "Ei hinta hevosta korota" (ryhmä 5).
#
#       Pilkku kulkee PÄÄSSÄ (kuten hollannissa, toisin kuin venäjässä):
#       suomi vaatii pilkun sivulauseen jälkeen, ja sivulause on päässä.
#       Katso ryhmä 2. Englanninkielinen peili ei ota pilkkua mukaan, koska
#       englanti ei sitä siinä kohdassa kirjoita.
#
#       CORNERCUT: ryhmässä 6 alun + merkitsee ENGLANNIN pään monikkoa, ei
#       suomen. Suomessa omistus on <adessiivi> on <nominatiivi>, eli
#       kieliopillinen subjekti on HÄNNÄSSÄ ja pää on paikka -- ja suomen
#       häntä ei muutu luvun mukaan lainkaan, joten merkintä ohjaa vain
#       peiliä. Jos jokin laitos joskus tarvitsee peilille OMAN lukunsa,
#       tämä on se rivi, joka pitää korjata.
#

#       molemmat: ha(s/ve) ja (its/their).
