#               Παροιμίες 0.5  —  ελληνική διασκευή του Ordsprak 0.1-και-κάτι
#               πρωτότυπο: Leif Claesson (Liket of Goto10), ~1996
#
#       Για τον Ριρή, στη Σίφνο. Ένα ραδιόφωνο κόβει και κολλάει ήχο όλη
#       μέρα -- ορίστε λοιπόν κι ένα πρόγραμμα που κάνει το ίδιο με τις
#       παροιμίες, και το κάνει επίτηδες λάθος. Καλώς να ορίσεις όποτε
#       αποφασίσεις να έρθεις.
#
#       (Και ναι, ξέρουμε τι σημαίνει το Θεόδωρος: θεός + δώρον. Δώρο
#       είναι λοιπόν κι αυτό -- χαλασμένο επίτηδες, αλλά δώρο.)
#
#       Στα ελληνικά, επειδή από εδώ ξεκίνησαν οι μισές. Η ίδια η λέξη
#       "παροιμία" -- παρά + οίμος, "στην άκρη του δρόμου" -- είναι ο
#       πρόγονος κάθε proverb, ordsprak, spreekwoord και пословица των
#       άλλων εκδόσεων. Εδώ λοιπόν η μηχανή δεν κομματιάζει μεταφράσεις:
#       κομματιάζει τα πρωτότυπα.
#
#       Και μια παγίδα για Σουηδό αναγνώστη, μιας και Σουηδός την έγραψε:
#       το ελληνικό ΝΑΙ ακούγεται ολόιδιο με το σουηδικό NEJ, που σημαίνει
#       ΟΧΙ. Ο συγγραφέας την έχει ήδη στήσει σε Έλληνα φίλο του, που στο
#       τηλέφωνο συμφωνούσε -- ναι, ναι, ναι -- ενώ σε σουηδικά αυτιά έλεγε
#       όχι, όχι, όχι. Του είπε "τι αρνητικός που είσαι", και ο άνθρωπος δεν
#       ξανάκουσε τη μητρική του γλώσσα με το ίδιο αυτί.
#
#       Το ίδιο και ο ΠΑΠΑΣ, που στα σουηδικά ακούγεται σαν pappa,
#       ο μπαμπάς: τα ράσα, λοιπόν, δεν κάνουν τον μπαμπά.
#
#       Το φορμά του αρχείου είναι πολύ απλό. Οι παροιμίες μπαίνουν σε
#       ομάδες μέσα στις οποίες τα μισά είναι γραμματικά ανταλλάξιμα, και
#       η ραφή είναι μια κάθετη γραμμή (|). Ένα σκέτο * ανοίγει την
#       επόμενη ομάδα. Το ** είναι το τέλος του αρχείου: ό,τι ακολουθεί
#       δεν το διαβάζει το πρόγραμμα.
#
#       Κάθε γραμμή έχει τέσσερα πεδία:  κεφάλι|ουρά|EN head|EN tail
#       Η αγγλική μετάφραση ανακατεύεται με το ΙΔΙΟ ζευγάρι δεικτών, οπότε
#       οι αγγλικές ανοησίες τρέχουν ακριβώς παράλληλα με τις ελληνικές.
#
#       ΤΑ ΕΛΛΗΝΙΚΑ ΡΗΜΑΤΑ ΚΛΙΝΟΝΤΑΙ ΚΑΤΑ ΑΡΙΘΜΟ, όπως τα αγγλικά και τα
#       ολλανδικά και σε αντίθεση με τα σουηδικά, τα ταϊλανδέζικα και τα
#       ρωσικά. Γι' αυτό η έκδοση αυτή κάνει ό,τι και η αγγλική: ένα +
#       στην αρχή της γραμμής σημαίνει ΠΛΗΘΥΝΤΙΚΟ ΥΠΟΚΕΙΜΕΝΟ, και η ουρά
#       κουβαλάει μόνη της και τους δύο τύπους:
#           (ει/ουν)        ενικός -ει, πληθυντικός -ουν
#           (εται/ονται)    μεσοπαθητική φωνή
#           (ά/ούν)         συνηρημένα, άλλη κατάληξη, άλλη ραφή
#       Και η ραφή δεν πέφτει πάντα στην κατάληξη: τρώ(ει/νε),
#       βρομά(ει/νε), βαρι(έται/ούνται). Καμία κανονική κατάληξη δεν τα
#       πιάνει όλα -- γι' αυτό η σήμανση κουβαλάει ΚΑΙ ΤΟΥΣ ΔΥΟ τύπους
#       αντί να παράγει τον έναν από τον άλλον.
#
#       ΤΟ "ΕΙΝΑΙ" ΔΕΝ ΠΑΙΡΝΕΙ ΣΗΜΑΝΣΗ. Στα νέα ελληνικά ο σύνδεσμος
#       είναι ίδιος στους δύο αριθμούς -- αυτός είναι, αυτοί είναι --
#       ενώ στα αγγλικά και στα ολλανδικά είναι το πιο συχνό σημαδεμένο
#       ρήμα ολόκληρου του αρχείου, (is/are) και (is/zijn). Εδώ απλώς
#       γράφεται σκέτο.
#
#       Η ΟΜΑΔΑ ΕΙΝΑΙ Η ΣΥΜΦΩΝΙΑ ΓΕΝΟΥΣ. Τα ελληνικά κατηγορούμενα
#       συμφωνούν σε γένος με το υποκείμενο, οπότε οι ουρές της ομάδας 1
#       είναι ΜΟΝΟ ρηματικές φράσεις: ούτε επίθετο κατηγορούμενο, ούτε
#       κτητικό (του/της), γιατί κι εκείνο έχει γένος. Δεν χρειάστηκε
#       καινούργιος κώδικας γι' αυτό. Η ομάδα του 1996 ΗΤΑΝ ήδη μια
#       κλάση ισοδυναμίας γένους και αριθμού -- απλώς τα σουηδικά δεν
#       την ζόρισαν ποτέ τόσο.
#
#       Η ομάδα 1 είναι επίτηδες παραφορτωμένη με ψεύτικες "ακριβές"
#       παροιμίες. Στο σουηδικό πρωτότυπο ήταν ψεύτικα dyr/dyrt/dyra,
#       τρεις τύποι. Τα ελληνικά θέλουν ΕΞΙ, γιατί το δόλωμα συμφωνεί σε
#       γένος ΚΑΙ σε αριθμό, και μαζί του αλλάζει και το άρθρο:
#           ο ακριβός σκύλος     η ακριβή γλώσσα      το ακριβό μήλο
#           οι ακριβοί τοίχοι    οι ακριβές γνώμες    τα ακριβά ράσα
#       Το δόλωμα ΕΙΝΑΙ το αστείο, και η σταθμισμένη επιλογή ομάδας
#       φροντίζει να πέφτει συχνότερα από οτιδήποτε άλλο.
#
#       Η ΣΤΙΞΗ ΤΑΞΙΔΕΥΕΙ ΣΤΟ ΚΕΦΑΛΙ (στα ρωσικά, αντίθετα, στην ουρά):
#       τα ελληνικά θέλουν κόμμα μετά από προτασσόμενη δευτερεύουσα, κι
#       εκείνη βρίσκεται στο κεφάλι. Δες την ομάδα 5.
#
