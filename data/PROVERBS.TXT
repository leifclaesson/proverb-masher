#       The file format is very simple. Sort proverbs into groups that fit
#       together grammatically, and put the pipe character (|) at the seam.
#       A lone * starts the next group. ** marks end of file -- the program
#       ignores every line after it.
#
#       Group 1 is deliberately stuffed with fake "expensive" decoys planted
#       next to their real partners (the original planted Swedish "dyr" the
#       same way), and the weighted group pick makes them dominate the
#       output. The decoys ARE the joke.
#
