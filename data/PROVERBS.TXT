#               Ordsprak 0.3  --  English remaster of Ordsprak 0.1-and-a-half
#               original by Leif Claesson (Liket of Goto10), ~1996
#
#       The file format is very simple. Sort proverbs into groups that fit
#       together grammatically, and put the pipe character (|) at the seam.
#       A lone * starts the next group. ** marks end of file -- the program
#       ignores every line after it.
#
#       ENGLISH-ONLY ADDITION -- number agreement, so singular and plural
#       subjects live in ONE group instead of being kept apart:
#
#         +      at the start of a line  = this subject is PLURAL
#         (s)    in a tail = there when the head is singular, gone when plural
#         (x/y)  in a tail = x when the head is singular, y when it is plural
#
#       The tail carries BOTH forms, so the program needs no grammar at all --
#       one search-and-replace and the seam holds either way. This is the only
#       direction that works: going the other way, deriving the base form from
#       an inflected one, is ambiguous even here ("rises" -> rise, "catches"
#       -> catch, same ending, different cut).
#
#       A tail whose verb doesn't inflect needs no mark at all: past tense
#       ("killed the cat") and modals ("will clutch at a straw") already fit
#       both. Two tails end in a plural NOUN and are deliberately left to
#       clash -- "can't be choosers", "will be boys". A mismatched verb reads
#       as a bug, a mismatched noun reads as the joke.
#
#       Group 1 is deliberately stuffed with fake "expensive" decoys planted
#       next to their real partners (the original planted Swedish "dyr" the
#       same way), and the weighted group pick makes them dominate the
#       output. The decoys ARE the joke.
#
#       Group 1 : subject | predicate   (biggest group = picked most often.
#       Swedish verbs don't conjugate for number, so the original got away
#       with one big group; this edition gets that one big group BACK by
#       marking the tails instead of splitting singular from plural.)
