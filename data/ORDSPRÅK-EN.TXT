#       The 1996 Swedish data file stays byte-for-byte pristine (still CP437),
#       so its English translations live here instead: same groups, same line
#       order, one EN head|EN tail per proverb. The site zips the two files
#       together and scrambles both with the same index pair, so the English
#       nonsense matches the Swedish one-to-one.
#
#       Swedish verbs don't conjugate for number, which is how the original
#       got away with one giant Group 1. English isn't so lucky, so these
#       tails are phrased agreement-neutrally (will/must/dashes) to survive
#       any head they get glued to.
#
